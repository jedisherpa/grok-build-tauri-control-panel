# Word-to-shape chain: implementation and qualification

Paul requested the dictionary → cross-language → SenseSnap → sentence-use chain and authorized the multi-agent workflow and local installation. Baseline e35298a; isolated branch codex/word-shape-chain. PM owns integration, runtime boundaries, phase gates and installed verification.

Implement an inspectable four-stage glyph for each retained word occurrence and sense alternative. Preserve existing fine E8 positions, root addresses and source identity. Layout stage coordinates are explicitly display/provenance coordinates; usage orientation is an explicit encoding of proposed roles/scope, not a learned semantic operator. Missing definitions, equivalence and geometry remain visible. Ordinary tokens outside the interpreter atom inventory must be counted and shown as uncovered rather than silently omitted.

Parallel implementation ownership:
- Core agent: crates/grok_cdiss/src/word_shapes.rs, public export and core tests. Function word_shapes(result: &Value) -> Result<Value, String>; accepts only an existing source-valid Joe result via analyze_joe_result. Output schema bomb-code/word-shapes/v1, status ready, sentence, language, basis, tokenCoverage, readings. Each reading has readingId, occurrences. Occurrences have atomId, surface, span, tokenPosition, sentenceTokenCount, roleBindings, alternatives, senseSnap, usageOrientation. Alternatives retain senseId, conceptIds, dictionary, crossLanguage, e8. Dictionary retains exact source IDs/definition/language/status; crossLanguage retains attributed alignment records and missingness; e8 retains unchanged native activation objects. TokenCoverage includes tokens with exact spans and covered status. All lists bounded, Unicode spans validated; no new mapping/authority.
- Dictionary agent: scripts/word_dictionary.py and tests. Read-only fixed root supplied by host; verify frozen manifest/file pins; actions query/coverage. Output schema bomb-code/dictionary-shapes/v1, status ready, coverage and paged hits. Every hit retains senseId, language, lemma, pos, definition, definitionLanguage, definitionStatus, sourceId, sourceRecordId, evidenceRefs, alignments, counterparts/counterpartCount, concepts with existing placements. All 34,801 encoded senses are queryable, including native-definition and position gaps. No network/model/provider calls; exact count and explicit truncation.
- Viewer agent: frontend/word-shapes.js, word-shapes.css and tests only. Expose global BombWordShapes.render(parent, attachment) and renderDictionary(parent, response), safe DOM/SVG, bounded lazy display. Four markers, directed provenance edges and inspectable native geometry/source details; declared usage arrow/role labels and token position. Missing markers stay visible. Dictionary mode uses the same four-stage vocabulary but labels sentence use unavailable until a sentence is interpreted. No evaluation of strings as markup; no provider calls.

PM wires these into Joe and adds a local dictionary browser, existing invalidation guards, native fixed-path worker command and offline source-backed test examples. Native attachments are saved with receipts. Advance local app version to 0.1.12. Do not modify the frozen reference or delete existing records. No remote push/publication.
