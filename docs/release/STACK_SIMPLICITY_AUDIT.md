## Assessment

Keep Rust/Tauri, the existing native adapters, reviewed BuildService/workflow engine, CDISS, source-defined dictionary/SenseSnap/E8, Joe and cited memory. The strongest simplification is one owner for each lifecycle, policy and durable outcome, then bounded rendering and workers. Dependency version counts alone do not justify a rewrite or deleting unique capabilities. Current correctness and resource gaps prevent claiming production qualification.

The earlier GPUI proposal supplies useful ownership and parity contracts. Its renderer migration, new distributed protocol and entire journal/outbox architecture are not prerequisites for every narrow Tauri repair. Start with the concrete defects in `STACK_ARCHITECTURE_AUDIT.md`, preserve existing data, then measure the exact repaired packaged candidate.

### SQLite release dependency gate

Root inspected the cached libsqlite3-sys 0.30.1 amalgamation and found SQLite **3.46.0**; app Persistence requests WAL/NORMAL. SQLite's official documentation describes the rare WAL-reset corruption bug affecting versions through 3.51.2 and fixes in 3.51.3, 3.44.6 and 3.50.7. Upgrade to a fixed supported dependency, prove actual runtime `sqlite_version()` and effective settings on the candidate, then rerun persistence/recovery/backups. This audit did not query an installed app's linked SQLite and did not reproduce corruption. Python history/recall use their own sqlite3 runtime: inventory and qualify those separately. A single connection lock reduces a scenario but is not a substitute for a patched dependency across multiple processes. [SQLite WAL-reset bug and durability documentation](https://www.sqlite.org/wal.html#walresetbug).

## Packaging, prerequisites and license closure

- Current Tauri bundle has no declared semantic reference/runtime resources. Root's new SemanticRuntime derives a host-owned `.grok/control-panel/wizard-joe` package and finds Node on absolute PATH locations. This removes a Paul-specific constant but does not install, verify or version that package. Finder PATH differs from an interactive terminal; a Node named file is not proof of execution/version. Ship a verified installation procedure or explicitly bundle pinned dependencies and qualify another user/clean Mac with absent/broken runtimes.
- History/recall prefer `/usr/bin/python3`, then Homebrew locations, without a declared minimum version; this Mac's system Python lacks `tomllib` (observed during this audit). Those workers mostly use stdlib today, but diagnose required capabilities rather than assuming Xcode/Homebrew/system runtimes are present on every Mac. Semantic Python additionally requires numpy/scipy; Node reference/code/data and local Ollama/Nomic need exact version/hash/resource manifests. No cloud indexing fallback is acceptable.
- Source `minimumSystemVersion=12.0` is a claim requiring actual oldest-supported macOS qualification for app, vendor CLIs and numerical/model dependencies. ARM64 qualification does not certify x86_64 or a universal dependency closure.
- Developer installer WIP correctly refuses an existing destination, retains signature and avoids automatic launch/notarization; build currently requires Grok even though Codex/Claude are independent routes. Separate build prerequisites from optional runtime routes and retain honest missing-backend diagnostics. `copytree` preserves file data/mode/symlinks but this audit did not verify macOS extended-attribute/signature preservation end to end; final copied artifact must pass the independent receipt/signature check.
- Repository MIT file is not complete third-party distribution clearance. Vendored model-viewer includes BSD-3-Clause headers and embedded dependencies; Joe provenance explicitly says no separate standalone asset license was found. Add a notices/dependency manifest and verify dictionary datasets, translations, model weights, reference source and Joe redistribution provenance. Owner-requested reuse supports this work but does not invent a third-party license. No full license or security-advisory scanner ran here.
- Preflight appropriately does not assert source-to-artifact provenance or feature qualification. Retain a deterministic build receipt, final signed dependency/runtime manifest, target-specific lock/toolchain pins, exact packaged story evidence and downloaded-quarantined artifact verification. Apple's acceptance does not repair any feature/resource defect above.
