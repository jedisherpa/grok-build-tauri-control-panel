- Roles, negation, modality, repeated occurrences, context-only pins, source alternatives and unmapped atoms survive representation.
- E8 positions, radius and codec metadata are retained byte-equivalently; scalar/vector state never normalizes or replaces native positions.
- Distances satisfy known zero/disjoint/symmetry cases and independent SciPy comparisons; mixtures remain finite nonnegative unit mass and are replayable.
- Context/source/model/config/thread changes reset comparison with visible reasons; malformed prior state, stale hashes, missing pins and out-of-scope receipt reads fail closed.
- Old donor action smoothing, permission floats, completion estimates, persona emotions and false configuration labels are absent from the port.
- Source-backed scripted fixtures exercise real adapter/library/host/UI paths. They do not qualify live model understanding or semantic usefulness of E8 proximity.
- Installed UI can show fresh, explicitly compared and invalidated states; user history and existing settings are preserved.
